# 뚝딱 - 네이버 블로그로 보내기 (Chrome 확장)

뚝딱 발행 화면의 **"네이버로 한 번에 보내기"** 버튼을 누르면 네이버 블로그 글쓰기(스마트에디터 ONE)에
제목·본문(서식 포함)·이미지를 자동으로 넣습니다. 발행 버튼은 누르지 않습니다.

확장이 없으면 앱 발행 화면에 **"Chrome에 추가"** 안내가 뜹니다(데스크톱 크롬·엣지·웨일, `NEXT_PUBLIC_EXTENSION_URL` 설정 시).
추가하고 탭으로 돌아오면 새로고침 없이 버튼이 바뀝니다(`background.js` 가 열린 탭에 브리지를 넣음).

## 동작
- `app-bridge.js` (뚝딱 페이지): 앱이 보낸 글을 확장 저장소에 5분간 보관합니다.
- `background.js`: 보낼 때 뚝딱 창을 화면 왼쪽 절반으로 줄이고, 네이버 글쓰기 창을 오른쪽 절반에 엽니다(iframe 은 네이버가 막아 창 두 개로 나눔).
- `naver-paste.js` (네이버 글쓰기): 보관된 글을 제목·본문 칸에 붙여넣고 보관본을 바로 지웁니다.
  "작성 중인 글이 있습니다" 팝업이 뜨면 사용자가 고를 때까지 기다립니다.
- 자동 입력이 안 되면 오른쪽 아래에 안내가 뜹니다. 본문은 이미 클립보드에 있으니 ⌘V 로 붙여넣으면 됩니다.

## 개발 중 설치
`chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다" → 이 폴더 선택.

## 크롬 웹스토어 등록 (한 번만)
1. `npm run ext:zip` → 프로젝트 루트에 `ddookddak-extension.zip` 생성
2. https://chrome.google.com/webstore/devconsole 에서 개발자 등록(1회 $5) 후 **새 항목** → zip 업로드
3. 스토어 등록정보: 아래 문구 사용, 스크린샷 1280×800 1장 이상(발행 화면 + 네이버에 들어간 모습)
4. 개인정보 보호 탭: 아래 "개인정보 처리" 문구 입력, 단일 목적 기재, 권한별 사유 입력
5. 공개 범위 **공개**(또는 링크가 있는 사용자만 = "미등록")로 심사 제출 → 보통 1~3일
6. 승인되면 상세 페이지 주소를 Vercel 환경변수 `NEXT_PUBLIC_EXTENSION_URL` 에 넣고 재배포

업데이트: `manifest.json` 의 `version` 을 올리고 다시 zip 업로드. 사용자 브라우저에는 자동 업데이트됩니다.

### 등록정보 문구
- 이름: 뚝딱 - 네이버 블로그로 보내기
- 요약: 뚝딱에서 만든 학원 블로그 글과 이미지를 버튼 하나로 네이버 블로그 글쓰기 화면에 넣습니다.
- 단일 목적: 뚝딱에서 작성한 글(제목·본문·이미지)을 네이버 블로그 글쓰기 화면에 자동으로 입력합니다.

### 권한 사유
- `storage`, `unlimitedStorage`: 뚝딱 탭에서 네이버 탭으로 글을 넘기는 동안(최대 5분) 이미지를 포함한 본문을 기기 안에 잠시 보관
- `scripting`: 설치 직후 이미 열려 있던 뚝딱 탭에서 새로고침 없이 연결
- `clipboardRead`, `clipboardWrite`: 네이버 에디터가 붙여넣기 신호를 받지 않을 때, 보낸 글을 클립보드에 넣고 브라우저의 붙여넣기 명령으로 제목·본문 칸에 입력
- `debugger`: 네이버 에디터가 스크립트 입력을 받지 않을 때, 글쓰기 탭에만 잠깐 연결해 실제 클릭과 붙여넣기(⌘V)를 보내고 바로 해제(그동안 크롬 위쪽에 "디버깅 중" 막대가 보임). 웹스토어 심사에서 이 권한의 사유를 함께 적어야 함
- 호스트(뚝딱 사이트, blog.naver.com): 뚝딱에서 글을 받고, 네이버 글쓰기 화면에 입력

### 개인정보 처리
이 확장은 사용자가 뚝딱에서 직접 보낸 글(제목·본문·이미지)만 사용자의 기기 안에 최대 5분 보관하고,
네이버 글쓰기 화면에 입력한 즉시 지웁니다. 어떤 데이터도 외부 서버로 전송하거나 수집하지 않습니다.

## 제한
- 네이버 에디터 구조가 바뀌면 자동 입력이 멈출 수 있습니다(클립보드 붙여넣기는 계속 동작).
- 앱 주소가 바뀌면 `manifest.json` 의 `content_scripts[0].matches` 를 고치세요(`host_permissions` 도 같이).
