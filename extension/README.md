# bbolog 네이버 붙여넣기 (Chrome 확장 프로그램)

웹페이지는 브라우저 보안 정책 때문에 다른 사이트(네이버) 탭에 글을 직접 넣을 수 없습니다.
이 확장 프로그램을 설치하면 bbolog **발행 준비 → "네이버 글쓰기 열고 붙여넣기"** 한 번으로
네이버 글쓰기 화면에 제목과 본문(서식 포함)이 자동으로 들어갑니다.

## 설치 (개발자 모드)
1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
4. bbolog 탭을 새로고침

## 동작
- bbolog(localhost)에서 버튼을 누르면 글을 확장 저장소에 5분간 보관합니다.
- 네이버 글쓰기 화면이 열리면 제목·본문 칸에 붙여넣기 이벤트로 넣고, 보관본을 바로 지웁니다.
- "작성 중인 글이 있습니다" 팝업이 뜨면 사용자가 고를 때까지 기다립니다(팝업을 대신 누르지 않음).
- 자동 입력이 안 되면 화면 오른쪽 아래에 안내가 뜹니다. 본문은 이미 클립보드에 복사되어 있으니 ⌘V로 붙여넣으면 됩니다.
- 이미지는 자동으로 올리지 않습니다. 본문의 `[이미지 n]` 자리에 직접 올려 주세요.

## 제한
- 네이버 에디터 구조가 바뀌면 자동 입력이 동작하지 않을 수 있습니다(이 경우 클립보드 붙여넣기로 대체).
- 앱을 localhost가 아닌 주소로 배포하면 `manifest.json`의 `matches`에 그 주소를 추가하세요.
